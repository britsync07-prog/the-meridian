# Plan 07-03: Measurement & Growth Features

## Goal
Implement GRO-01 through GRO-09: newsletter, weather, traffic measurement, domain migration.

## Requirements
- GRO-01: Reader can subscribe to daily digest for one edition
- GRO-02: Subscriber receives one email per day for their edition
- GRO-03: Newsletter send volume monitored against provider daily cap
- GRO-04: Newsletter signup form submits server-side; API key never reaches browser
- GRO-05: Newsletter signup form sits outside critical rendering path
- GRO-06: Each edition shows live weather for country centroid + major cities
- GRO-07: Weather fetch failure never fails build; last cached forecast served
- GRO-08: Traffic measured with Cloudflare Web Analytics and Google Search Console
- GRO-09: Custom domain reachable via 301 redirects from build subdomain
