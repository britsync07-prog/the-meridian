# Plan 07-02: Operational Workers

## Goal
Implement OPS-02, OPS-03, OPS-15, OPS-16, OPS-17, OPS-18 workers and guards.

## Requirements
- OPS-02: Daily audit Worker reports free-tier metrics as percentage of ceiling
- OPS-03: Alerts fire at 50% and 75% thresholds
- OPS-15: Raw item rows pruned 30 days after merge window closes
- OPS-16: Build-in-progress guard prevents overlapping builds
- OPS-17: Edge routing fails open on quota exhaustion
- OPS-18: Site never returns 5xx or 429 to Googlebot

## Tasks

### Task 1: Audit Worker (OPS-02, OPS-03)
- [ ] Create `apps/worker/src/audit.ts` — daily audit handler
- [ ] Read D1 usage stats (rows read/written, storage)
- [ ] Calculate percentages against free-tier-limits.json
- [ ] Send alerts via Brevo webhook at 50% and 75%
- [ ] Write usage report to R2 for admin page
- [ ] Add tests for audit logic

### Task 2: Pruning Worker (OPS-15)
- [ ] Create `apps/worker/src/prune.ts` — raw item pruner
- [ ] Delete raw_items rows older than 30 days from merge date
- [ ] Preserve cluster outlet_list, headline, url permanently
- [ ] Add safety checks (never prune clusters)
- [ ] Add tests for pruning logic

### Task 3: Build-in-progress guard (OPS-16)
- [ ] Create R2 lock file mechanism in `scripts/build-guard.ts`
- [ ] Check lock before build starts
- [ ] Set lock with TTL (e.g., 30 minutes)
- [ ] Release lock on build completion (success or failure)
- [ ] Add tests for guard behavior

### Task 4: Fail-open routing (OPS-17, OPS-18)
- [ ] Update `apps/worker/src/index.ts` — add Googlebot detection
- [ ] Return cached fallback on quota exhaustion
- [ ] Never return 5xx or 429 to any user agent
- [ ] Add health check endpoint
- [ ] Add tests for fail-open behavior

### Task 5: Worker configuration
- [ ] Add cron triggers to wrangler.jsonc for audit and prune
- [ ] Document worker endpoints
- [ ] Add integration tests

## Files to Create/Modify
- `apps/worker/src/audit.ts` — new audit worker
- `apps/worker/src/prune.ts` — new pruning worker
- `scripts/build-guard.ts` — new build guard
- `apps/worker/src/index.ts` — update with fail-open logic
- `apps/worker/wrangler.jsonc` — add cron triggers
- `apps/worker/__tests__/audit.test.ts` — new tests
- `apps/worker/__tests__/prune.test.ts` — new tests

## Success Criteria
- Audit Worker runs daily, reports metrics
- Alerts fire at correct thresholds
- Raw items pruned after 30 days
- Overlapping builds prevented
- No 5xx/429 responses to Googlebot
