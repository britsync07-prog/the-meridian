<objective>
Build the two-gate clustering engine and validate it against a 200+ hand-labelled headline pair benchmark, enforcing the non-negotiable quality gate: Precision $\ge 98\%$ and Recall $\ge 85\%$ (CUR-01, CUR-06, Spike S-7).

Purpose: Curation is the core differentiator of The Meridian. False merges pollute stories with contradictory facts, while missed merges fracture coverage across duplicate clusters. Candidate generation must query D1 band indexes without table scans (OPS-14), and semantic confirmation must utilize `@cf/baai/bge-m3` vectors with offline fixture fallback (D-20).

Output: Benchmark datasets (`headline-pairs.json`, `headline-embeddings.json`), vector embedding provider, two-gate clustering engine (`src/curation/cluster-engine.ts`), repository method `findLshCandidates`, and passing benchmark suite (`tests/curation/merge-benchmark.test.ts`).
</objective>
