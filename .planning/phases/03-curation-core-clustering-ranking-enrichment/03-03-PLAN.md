   - Implement `calculateTrendingScore(input: TrendingScoreInput): number`:
     Extract:
     `distinctOutlets = Math.max(1, input.distinctOutlets);`
     `totalMentions = Math.max(distinctOutlets, input.totalMentions);`
     `distinctSections = Math.max(1, input.distinctSections ?? 1);`
     `ageHours = calculateAgeHours(input.publishedAt, input.nowIso);`

     ```ts
     const outletTerm = 3.0 * Math.log2(1 + distinctOutlets);
     const mentionTerm = 1.0 * Math.log2(1 + totalMentions);

     const sectionTerm = 0.8 * Math.min(1, Math.max(0, distinctSections - 1));
     const rawScore = outletTerm + mentionTerm + recencyTerm + sectionTerm;
     return Math.round(rawScore * 1000) / 1000; // round to 3 decimal places
     ```
