## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo → CI | Anything committed to the repository is executed by GitHub Actions and shipped to the public site |
| CI → Cloudflare account | Wrangler commands in CI act on the live account with its API token |
| edge runtime → shared contract | The Worker and the Astro site both import `shared/`; a change there reaches both at once |
