| Local Ingest Script → Local D1 | Unsanitized SQL execution during offline development |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-16 | D | `apps/worker/src/fetcher/index.ts` | mitigate | Cascading failure where a hung feed socket exhausts execution time for subsequent feeds in the partition (ING-07). Mitigate by enforcing strict 10s `AbortSignal.timeout` per feed and isolating each feed execution in a `try/catch` block so individual errors never bubble up to cancel the partition. |
| T-02-17 | T | `apps/worker/src/db/repository.ts` | mitigate | SQL injection during batch story insertions from feed headlines or excerpts (D-26). Mitigate by using prepared parameterized statements (`?`) in chunks via `db.batch()` inside `repository.ts`. |
