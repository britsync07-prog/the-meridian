<objective>
Implement the fetch-only Ingest Worker on Cloudflare Edge: 3 partitioned cron triggers, polite HTTP fetching with per-host rate limits, KV-backed conditional GET, response sniffing for XML vs bot challenges, hard 2 MB streaming byte limiter, and raw snapshot/quarantine storage in Cloudflare R2.

Purpose: Feed acquisition must operate within the strict limits of the Workers Free plan (10 ms CPU per invocation, 50 subrequests, 6 simultaneous sockets). The Worker only moves bytes from publishers to R2 and state to KV; it performs zero parsing or scoring, protecting the CPU ceiling and isolating bad feeds from healthy feeds (ING-01, ING-02, ING-07, ING-10).

Output: Tested edge fetcher with 3 cron partitions, KV polling state, polite crawling guarantees, stream-level quarantine isolation, and an automated Worker purity test.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External Feed Server → Worker Fetcher | Hostile/malformed HTTP responses, decompression bombs, HTML challenge masquerading as XML |
| Worker Fetcher → Cloudflare KV | State corruption, excessive write frequency breaching 1,000 writes/day free ceiling |
| Worker Fetcher → Cloudflare R2 | Storage exhaustion or unbounded object creation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-05 | T | `apps/worker/src/fetcher/quarantine.ts` | mitigate | Publisher serves Cloudflare Turnstile or PerimeterX HTML challenge page with HTTP 200, which would break downstream XML parser (ING-07).
