# Plan 05-03: RSS Feeds & Internal Link Graph

## Objective

Generate RSS feeds for every edition, every section, and a global feed. Generate an internal link graph from the cluster graph ensuring all indexable URLs are reachable within 3 clicks from any front page.

## Tasks

### Task 1: RSS feed generator (`apps/site/src/lib/rss.ts`)

**Type:** feature  
**Action:** Create RSS feed generation utility.

Files to create:
- `apps/site/src/lib/rss.ts` — NEW: RSS feed builder

The module must:
1. Accept snapshot data + edition/section filter
2. Generate valid RSS 2.0 XML
3. Include: title, link, description, item (title, link, guid, pubDate, excerpt, sources)
4. Per-edition feed: all stories for that edition
5. Per-section feed: all stories in that section across all editions
6. Global feed: all stories across all editions
7. Use site origin from config for absolute URLs
8. Conform to CON-07 (excerpt provenance)

**Verify:** `npm test -- --run apps/site/__tests__/rss.test.ts`  
**Acceptance criteria:** Valid RSS XML; all URLs absolute; excerpts verbatim

### Task 2: RSS page routes

**Type:** feature  
**Action:** Create Astro page routes for RSS feeds.

Files to create:
- `apps/site/src/pages/[edition]/rss.xml.ts` — NEW: per-edition RSS
- `apps/site/src/pages/rss.xml.ts` — NEW: global RSS

Both must:
1. Use `getStaticPaths()` for edition slugs + global
2. Call `rss.ts` generator with appropriate filters
3. Return `Response` with `Content-Type: application/rss+xml`

**Verify:** `npm run build` produces RSS files in dist  
**Acceptance criteria:** `/uk/rss.xml`, `/us/rss.xml`, `/rss.xml` all valid RSS

### Task 3: Internal link graph (`apps/site/src/lib/internal-links.ts`)

**Type:** feature  
**Action:** Generate internal link graph from cluster data.

Files to create:
- `apps/site/src/lib/internal-links.ts` — NEW: link graph builder

The builder must:
1. Parse cluster graph from snapshot
2. Generate links between: story↔story (same section), story↔topic, story↔entity, story↔edition
3. Ensure every indexable URL is reachable within 3 clicks from any front page
4. Output as a JSON manifest for page rendering
5. Max 3 outgoing links per story (prevent link spam)

**Verify:** Graph reachability test — BFS from each front page, all URLs within 3 hops  
**Acceptance criteria:** PUB-06 satisfied — all indexable URLs within 3 clicks

### Task 4: Link injection in layouts

**Type:** feature  
**Action:** Inject internal links into story and section pages.

Files to modify:
- `apps/site/src/layouts/StoryLayout.astro` — MODIFY: add "Related stories" section
- `apps/site/src/layouts/SectionLayout.astro` — MODIFY: add "More in this section" links
- `apps/site/src/layouts/FrontLayout.astro` — MODIFY: add cross-edition links where applicable

**Verify:** Built pages contain `<a>` tags to related content  
**Acceptance criteria:** No infinite scroll or auto-refresh; all links are ordinary anchors
