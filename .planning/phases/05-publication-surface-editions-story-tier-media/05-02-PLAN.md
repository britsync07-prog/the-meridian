# Plan 05-02: Edge Worker Story Tier & Media Pipeline

## Objective

Wire the edge Worker to serve `/story/*` pages from R2 with proper caching headers (ETag, Cache-Control). Implement the media pipeline: fetch source images, resize to WebP variants via sharp, generate OG images via satori+sharp, store content-addressed by sha256(source_url).

## Tasks

### Task 1: Story router (`apps/worker/src/story-router.ts`)

**Type:** feature  
**Action:** Create the story tier router module.

Files to create:
- `apps/worker/src/story-router.ts` — NEW: serves `/story/*` from R2

The router must:
1. Parse `/story/{slug}` from request path
2. Fetch `story/{slug}.html` from R2 bucket `meridian`
3. Return with:
   - `Content-Type: text/html; charset=utf-8`
   - `ETag: "{sha256-of-body}"`
   - `Cache-Control: public, max-age=300, stale-while-revalidate=86400`
4. Return 404 if not found in R2
5. Support `If-None-Match` for conditional requests

**Verify:** `curl -I http://localhost:8787/story/test-slug` returns correct headers  
**Acceptance criteria:** Story pages served from R2 with proper caching; 404 on missing

### Task 2: Worker integration (`apps/worker/src/index.ts`)

**Type:** feature  
**Action:** Integrate story router into main Worker fetch handler.

Files to modify:
- `apps/worker/src/index.ts` — MODIFY: add story routing

Update the `fetch` handler to:
1. Match `/story/*` and delegate to `story-router.ts`
2. Match `/api/*` and delegate to existing API handlers
3. All other paths → static asset (handled by Cloudflare CDN)
4. Set `not_found_handling: "none"` in wrangler config

**Verify:** Worker starts without errors  
**Acceptance criteria:** `/story/{slug}` routes to R2; `/api/*` routes to API; everything else to CDN

### Task 3: Media pipeline (`src/curation/media.ts`)

**Type:** feature  
**Action:** Implement content-addressed image pipeline.

Files to modify:
- `src/curation/media.ts` — MODIFY: add image processing pipeline

The pipeline must:
1. Accept source URL → compute `sha256(source_url)` as content key
2. Check R2 for existing variant; skip if exists (idempotent)
3. Fetch source image from URL
4. Resize to 1000px width WebP → R2 `media/{key}-1000w.webp`
5. Resize to 400px width WebP → R2 `media/{key}-400w.webp`
6. Generate 1200×630 JPEG OG image via satori+sharp → R2 `media/{key}-og.jpg`
7. Set `Cache-Control: public, max-age=31536000, immutable` on all variants
8. Return variant URLs for embedding

Error handling: if source image fetch fails, return `null` for all variants (never fails the build)

**Verify:** `npm test -- --run tests/curation/media.test.ts`  
**Acceptance criteria:** Images processed once, served from custom media domain, never r2.dev

### Task 4: Media handler in Worker (`apps/worker/src/media-handler.ts`)

**Type:** feature  
**Action:** Create media serving handler.

Files to create:
- `apps/worker/src/media-handler.ts` — NEW: serves media variants from R2

The handler must:
1. Match `/media/*` paths
2. Serve from R2 with immutable cache headers
3. Never serve from default R2 dev domain — use custom media domain
4. Return 404 for missing media

**Verify:** Media endpoints return correct Content-Type and cache headers  
**Acceptance criteria:** Media served with 1-year immutable cache
