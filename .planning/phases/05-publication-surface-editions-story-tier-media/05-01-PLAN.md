<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| D1 → Snapshot Script | Injection via malformed DB data into snapshot JSON |
| Snapshot → Astro Build | Corrupted or incomplete snapshot causing page generation errors |
| Assertions → Build Result | Assertion bypass letting a thin edition through |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | T | `scripts/snapshot/generate-snapshot.mjs` | mitigate | Snapshot script only reads through repository.ts; never opens raw SQL. All values are parameterized. |
| T-05-02 | E | `apps/site/src/lib/snapshot.ts` | mitigate | Snapshot reader validates the schema_version field and rejects unknown versions. A corrupted blob causes a controlled error, not a silent fallback to SAMPLE_STORIES. |
| T-05-03 | E | `scripts/assert/build-assertions.ts` | mitigate | Assertions throw on failure (never returns false to a caller that can ignore it). The CI step `set -e` ensures non-zero exit propagates. |
</threat_model>
