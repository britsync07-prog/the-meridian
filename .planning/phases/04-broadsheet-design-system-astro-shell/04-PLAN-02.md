# Phase 4 Plan 2: Font Setup & Typography

## Scope
Self-host OFL fonts and configure proper loading:
- Playfair Display (Regular, Bold, Italic) for headlines/display
- Noto Serif Devanagari (Regular, Bold) for Hindi edition
- System UI stack for body text
- WOFF2-only delivery with `font-display: swap`
- `size-adjust` descriptor for CLS safety

## Files to Create/Modify
- Download Playfair Display WOFF2 files to `apps/site/public/fonts/`
- Download Noto Serif Devanagari WOFF2 files to `apps/site/public/fonts/`
- `apps/site/src/styles/global.css` — add `@font-face` declarations
- Configure unicode-range partitioning (Latin, Latin-Extended, Devanagari)

## Tasks
1. **Download Playfair Display** from Google Fonts (WOFF2 only)
2. **Download Noto Serif Devanagari** from Google Fonts (WOFF2 only)
3. **Create @font-face declarations** with proper src, unicode-range, font-display: swap
4. **Add size-adjust fallback** to prevent CLS > 0.1
5. **Configure type scale tokens** in Tailwind config

## Verification
- Fonts load correctly in both themes
- CLS remains under 0.1 with font-swap
- Devanagari text renders correctly in Hindi edition

## Risk
- Font file size may impact LCP — monitor in Lighthouse CI
