# Phase 4 Plan 4: Accessibility Baseline

## Scope
Implement all accessibility requirements:
- Skip-to-content link (first Tab stop)
- Focus-visible indicators (≥2px ring, 3:1 contrast)
- Focus not obscured by sticky masthead (DSN-07)
- Contrast ratios in both themes (4.5:1 text, 3:1 non-text)
- Semantic landmarks
- `prefers-reduced-motion` support
- 360px single-column usability

## Files to Create/Modify
- `apps/site/src/styles/global.css` — focus styles, reduced-motion
- `apps/site/src/layouts/Base.astro` — skip-to-content link
- All layout templates — landmark structure

1. **Add skip-to-content link** — first element in DOM, visible on focus
2. **Implement focus-visible styles** — 2px ring, accent color, offset
